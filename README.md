📌 Project Overview

This project is a KFC Sales Analysis Dashboard created using Power BI and SQL.
The dashboard provides insights into sales performance across different countries, branches, and years.
🛠 Tools & Technologies

SQL Server – Data extraction & querying

Power BI – Data visualization & dashboard creation

DAX – Measures and calculations
📂 Dataset Description

The dataset contains sales data with the following columns:

Sales_ID

Year

Month

Country

Branch_ID

Sales

Customers

Marketing_Spend

Total Records: 8000 rows
📊 Dashboard Features

Total Sales KPI

Total Customers KPI

Total Marketing Spend KPI

Sales by Branch ID (Bar Chart)

Sales Trend by Year (Line Chart)

Sales by Country (Map & Bar Chart)

Country Slicer for filtering

📈 Key Insights

Sales performance varies significantly across countries.


Certain branches contribute higher revenue compared to others.

Sales show an upward trend in recent years.

Marketing spend has a visible impact on sales growth.
🧮 SQL Queries Used

Retrieved column metadata using INFORMATION_SCHEMA.COLUMNS

Used sys.columns for table structure validation

Aggregated sales data using SUM() and GROUP BY

Sorted sales by branch and country

Practice SQL querying

Learn Power BI dashboard design

Perform sales performance analysis
